# Project Memory

## Brand Facts

Facts about the **brand, product or organization** — not about any one campaign. This section **survives a spec
reset**: start a new project for the same brand and `project-spec.md` begins empty, while these rows carry over
and `/cdp:onboarding` reads them instead of asking again.

A fact belongs here only if it passes **both** tests: it doesn't depend on the current campaign, **and** another
campaign on the same brand would need it again. Keep the filter tight — most answers are campaign-bound and
belong in `project-spec.md` alone.

**Nothing is written here without explicit confirmation.** A fact proposed and not confirmed is not a fact.

| Fact | Feeds | Source | Status | Date |
|------|-------|--------|--------|------|
| | | | | |

- **Feeds** — which `project-spec.md` section it fills (§1 Brand Identity, §2 Target Audience, §6 Tone of Voice,
  §8 Competitive Positioning, §9 Constraints are the usual ones; the test decides, not the section number).
- **Source** — `interview`, or the document/path it came from.
- **Status** — `draft` (from an interview, not yet grounded in a durable source) · `current` (grounded in a
  document, or confirmed across more than one project) · `superseded (YYYY-MM-DD)` (a later project contradicted
  it — keep the row, name what replaced it). A fact that changed is more interesting than one that never did.
