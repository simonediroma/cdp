# cdp — Constructive Demolition Protocol

A method, and a Claude plugin, for finding the blind spots in a specification before reality does — then carrying the hardened spec through to UX, wireframes, mockups and working code.

## Start here

| | |
|---|---|
| **[Minicourse](minicourse/README.md)** | Five short courses, from a rough idea to a hardened spec, a deployed PoC, and a product in production. |
| **[Manifesto](document/cdp-manifesto.md)** | The protocol itself: phases, personas, severity, exit criteria. |
| **[Foundations](document/cdp-foundations.md)** | Why it works: origin, meta-principle, augmented humans, references. |

## Install the plugin

```
/plugin marketplace add simonediroma/cdp
/plugin install cdp@simonediroma-cdp
```

Source, skills and full README on [GitHub](https://github.com/simonediroma/cdp).
